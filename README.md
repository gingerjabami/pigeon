# Pigeon 🕊️


### 📜 About

Pigeon is a playful yet functional delivery platform that reimagines the classic pigeon carrier concept. Whether you're sending heartfelt messages, small packages, or a delightful surprise, Pigeon makes your deliveries take flight—literally.

Tagline: Send messages, packages, or even surprise pops to anyone—Pigeon takes your deliveries to the sky.
#
### ✨ Features

- **Send Messages** 📩 - Send personalized messages to anyone, anywhere
- **Send Packages** 📦 - Ship small packages to your friends and family
- **Big Pop** 💥 - Surprise someone with a fun "pop" experience
- **Order Tracking** 🔍 - Track all your pigeon deliveries in one place
- **Responsive Design** 📱 - Works on desktop and mobile devices
#
### 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/gingerjabami/pigeon.git
   ```

2. Navigate to the project directory:
   ```
   cd pigeon
   ```

3. Open the `index.html` file in your browser:
   - Double-click the file
   - Or use a local development server like Live Server in VS Code

No additional dependencies or installations are required as this is a static HTML/CSS/JavaScript project.

## 🧰 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Storage**: Local Storage for order management
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins, Lobster)

#
### 💡 Inspiration
The idea started as a lighthearted thought—what if pigeons could do more than just fly around and stir up a little chaos? Inspired by the meme culture, I decided to build Pigeon, a fun yet functional spin on the traditional carrier pigeon, adapted for the digital age.
#
### 🛠️ How I Built It
I took the nostalgic concept of pigeons delivering messages and gave it a modern twist—think of it as Uber, but for pigeons. I used HTML, CSS, and JavaScript to bring the platform to life, relying on local storage to handle messages and package data while virtual pigeons manage the rest.
#
### 🏆 Accomplishments

I'm proud to say I turned a meme into a working delivery platform. The pigeons? They do their jobs—most of the time. And the “Big Pop” feature always gets a smile. It's been a joy building something that blends humor with functionality.
